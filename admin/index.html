Đăng Nhập Quản Trị

Nhập Mã Token GitHub của bạn để có quyền thêm/sửa sản phẩm & môn tập trực tiếp.

💡 Cách lấy mã Token (chỉ làm 1 lần):
1. Vào Tạo GitHub Token Nhanh
2. Chọn thời hạn: No expiration (vĩnh viễn)
3. Tích chọn quyền repo ➔ Bấm Generate token
4. Copy mã token và dán vào ô trên là xong!
